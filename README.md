# KidicalMass

Platform voor KidicalMass-groepen in België. Beheer van groepen, activiteiten, artikels, partners en contactformulieren.

## Vereisten

- PHP 8.4
- MySQL
- Node.js
- [Laravel Herd](https://herd.laravel.com)

## Installatie

```bash
git clone https://github.com/ndeblauw/kidicalmass
cd kidicalmass
composer run setup
```

De site is beschikbaar op `https://kidicalmass.test`.

## Ontwikkeling

```bash
composer run dev
```

## Stack

- Laravel 12
- Livewire 4 + Flux UI Pro
- Filament v5
- Tailwind CSS v4
- Pest
