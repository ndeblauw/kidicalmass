# Public Site Head (SEO & Social Sharing Baseline) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stub public `<head>` with a full SEO/social baseline: branded title pattern, per-page meta descriptions, canonical, Open Graph/Twitter tags, two-tier OG images, favicons, theme-color, manifest.

**Architecture:** All head output moves into one `@include`d partial (`partials/site-head.blade.php`) fed by the existing Blade prop cascade on `<x-layouts::site>` (`title`, new `description` / `og-image` / `og-type`). Activities and Articles gain an `og` Medialibrary conversion (1200×630 jpg) plus `metaDescription()` / `ogImageUrl()` helpers; Groups (no content field) use a templated lang key. Static page copy lives in `lang/nl/meta.php`.

**Tech Stack:** Laravel 13 Blade components, spatie/laravel-medialibrary conversions, Pest 4 feature tests. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-07-03-seo-head-design.md`

## Global Constraints

- Shared checkout with another committer: stage by explicit path only, NEVER `git add -A`, never push.
- All user-facing copy is Dutch, follows `docs/tone-of-voice.md`, and contains NO em-dashes.
- Tests follow `docs/testing-conventions.md`: assert `__('key')` values and observable attributes, never literal long copy or utility classes. Do not delete tests.
- After any PHP edit: `vendor/bin/pint --dirty --format agent`.
- Run tests with `php artisan test --compact --filter=<Name>`.
- Do not modify `resources/css/app.css` (the theme-color hex `#1d67cd` is copied FROM its `--color-kidical-blue` token, defined at line ~39).
- No new composer/npm packages.
- Site name string is exactly `Kidical Mass België`; title separator is exactly ` · ` (middle dot).
- When writing tests, activate the `pest-testing` skill; when touching media conversions (Task 2), activate the `medialibrary-development` skill.

}
