Open flanks (nothing exists yet)

  • Newsletter is a stage prop. Signup forms live on 4+ pages; no subscriber model, no double opt-in, no send path.
  • No analytics, no error monitoring, no uptime check. Launch would be flying blind.
  • The critique queue is all one person. 10 Wire rows sit orange waiting on Frederik's own pass (About ×7, roze-hub, Contact, Privacy) — the single biggest block on the board, and no code moves it.
  • No hosting / DNS / cutover plan anywhere in the wiki; queue worker, mail deliverability and backups undecided.
  • FR locale unbuilt despite the v1 "NL + FR routed" strategy promise; middleware and lang/fr don't exist.

Hosting, deploy & cutover plan

The wiki's one true blank page. Production env, DNS switch, queue worker (opt-in mails and media conversions need one — without it, conversion jobs queue forever and pages silently serve raw originals), media-library:regenerate on prod, SPF/DKIM so form mail lands, backups, and the open migration question: parallel-run Wix or hard switch?
