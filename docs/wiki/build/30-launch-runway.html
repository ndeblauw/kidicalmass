Already banked (don't redo these)

  • SEO & social share baseline shipped 07-03: titles, NL descriptions, canonical, OG/Twitter cards, favicons, webmanifest (D-10 → Partly).
  • Branded error pages (404/403/419/500/503) with tests; dead Wix links at least fail gracefully.
  • 110 test files + CI (Pest + Pint on GitHub Actions) and a cross-cutting mobile pass (20 pages, zero overflow).
  • Admin with role scoping live & tested; duo + chapter-lead access model works.
  • Real data on real pages: chapters finder (27 pins), press archive (23 entries), about-stats, quotes/team CMS, partner strip.
  • Redirect map designed (D-7 closed) and a demo runbook (demo-journeys.md) that already audits real vs faux.

Open flanks (nothing exists yet)

  • No Wix redirects built. The map exists on paper; routes/web.php only has internal 301s. Old links, including every Facebook /agenda link, hit a 404 today.
  • Newsletter is a stage prop. Signup forms live on 4+ pages; no subscriber model, no double opt-in, no send path.
  • No analytics, no error monitoring, no uptime check. Launch would be flying blind.
  • Privacy and national Contact are stubs, while forms already collect personal data (GDPR clock is real).
  • No hosting / DNS / cutover plan anywhere in the wiki; queue worker, mail deliverability and backups undecided.
  • FR locale unbuilt despite the v1 "NL + FR routed" strategy promise; middleware and lang/fr don't exist.

The weighed board

22 initiatives, four lanes, weighed

Lanes are ordered by when they bite. Impact dots = how much the item moves launch or protects it (●●● = launch fails or embarrasses without it). Effort is calendar-honest: S = a session, M = a thread or two, L = a real project. Pink-bordered cards are the ones I'd argue can't slip.

Can't cut over without

Launch blockers

The site can be revealed without these, but it cannot replace kidicalmass.be without them. All five are known, scoped, and mostly Nico-shaped.

Build the Wix redirect map

The design side is done (26-redirect-map.md). Still to build: the routes themselves, the locale middleware the map assumes, slugs for the Grande KM redirects, and a post-launch crawl. /agenda → /events carries every old Facebook link.

MNico

Wire the newsletter backend

Subscriber model + double opt-in + the glue mailable. The hard parts already exist and are tested (per-group change computation, themed mail template); what's missing is the join. Until then, four live-looking forms silently drop email addresses.

MNico

Privacy page (P-06)

A stub today, but GDPR-mandatory: the site already collects names, emails and chapter choices via the enquiry and opt-in forms. Needs legal text more than design; a cookieless analytics choice (see below) keeps it banner-free.

S–MFrederik

National contact page (P-05)

The press/partnership front door has a route and nothing else, and Press/Partners pages point at it. The contact backend (form → duo inbox) already works, so this is a UX + copy job, not a build job.

MFrederik

Hosting, deploy & cutover plan

The wiki's one true blank page. Production env, DNS switch, queue worker (opt-in mails need one), media-library:regenerate on prod, SPF/DKIM so form mail lands, backups, and the open migration question: parallel-run Wix or hard switch?

People & content

The human runway

The registry's weakest number is content confidence (2.3/5), and none of it is code. This lane runs on other people's calendars, so it starts earliest even though it finishes last.

The Leticia decision batch

Six blockers, one structured session: mission + one-liner sign-off (S-1/S-2), trekker consent (flagged BLOKKEREND), one-off support + IBAN, the national partner pass, enquiry ownership (D-12), press dates. Highest impact-per-hour item on this page.

SLeticia+ Frederik

Content confidence push

Duo photos + bios, ~6 uncleared partner logos, per-event photos and Komoot embeds, the hero MP4, two quote translations. The chase list already exists per page in the registry's Top gaps; turn it into one client-facing checklist.

M–LClient+ Frederik

Chapter-lead onboarding

The migration plan's own words: the biggest transition risk. ~13 Brussels chapter pages launch near-empty; leads need an authoring guide, a session, and a decided moment to stop editing Wix. This is a launch feature, not documentation.

MFrederik+ leads

Admin handoff for the duo

News, press, partners, quotes, team, year stats are all admin-editable now; nobody but you two knows that. Short screencasts beat a manual, and they double as reveal material ("you can change this yourselves").

S–MFrederik

Ops safety net

Error monitoring (Flare fits the Laravel stack), an uptime ping, and a verified backup before real users arrive. An hour of setup that decides whether the first production bug is an email or a rumour.

SNico

Reveal runbook

Adapt demo-journeys.md from the volunteer demo into a client-reveal script: which journeys to walk, what's real vs faux (say it before they find it), and how feedback gets captured into the OK column instead of a WhatsApp thread.

SFrederik

After the reveal

Post-launch / v1.x

Real work, wrong week. Naming it now protects the launch from scope creep; the FR call is the one that needs an honest conversation rather than a default.

FR locale: decide, then build

Strategy promises NL + FR routed in v1; nothing FR exists (middleware, lang/fr, per-page copy, hreflang). Either it blocks the cutover or it's an announced fast-follow. Deciding beats drifting: it also unblocks the redirect middleware and hreflang.

LFrederik+ Nico

The #37 backend bundle

Per-chapter enquiry routing (waits on the D-12 ownership call), roze-hub real features (gallery upload, change feed, materials), per-group intro/cover fields. Volunteers-facing, not visitor-facing, so it can trail the public launch.

LNico

Post-launch SEO ops

Search Console + sitemap submission, crawl the redirect-critical set (301 → 200), watch the 404 log for unmapped Wix paths for a month, run the media regenerate. The redirect map explicitly asks for this verification pass.

SNico

My activities + volunteer growth path

P-08 is still a provisional spec, and D-1's remainder (the three-layer material library) needs specing. Clean v1.1 scope: the volunteer loop, deepened.
