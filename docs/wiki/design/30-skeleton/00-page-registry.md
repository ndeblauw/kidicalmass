# Skeleton — page registry & build pipeline

Every page/route as one row, with its **honest pipeline status**. This table is the single source of truth; the read-only **`/build`** dashboard (non-prod, unlinked) parses it live. Update procedure + honesty gate live in [`CLAUDE.md`](../../../../CLAUDE.md) → "Updating the build pipeline" (or run `/pipeline`).

**Phases:** `UX` briefing · `Conf` content-confidence (1–5) · `Wire` wireframe (content + hierarchy, no style) · `Assets` media in · `UI` visual style · `Back` backend/CMS wired & verified · `OK` client sign-off.
**Status:** 🔴 niet begonnen · 🟠 bezig · 🟢 goed · ⚪ n.v.t. · ❓ te beslissen. `OK` is binary (🔴/🟢).

## Roll-up

- **Pages:** 23 rows (`P-01`–`P-23`). **UX:** 19 🟢 · 1 🟠 (My activities) · 3 🔴 (stubs: Contact, Legal, Login). **Avg content-confidence ≈ 2.3 / 5** — client material still pending across most pages.
- **Wire/UI 🟢 (Frederik-approved):** **Help out** — through the full design pass + Frederik's own critique; updated 2026-06-15 (roles carousel + location-picker gate + start-een-groep repoint) with no regression. Only `OK` (client sign-off) remains.
- **Wire 🟢 / UI 🟠 (Frederik wire-approved):** **Home, Events, Event detail** — wire-critiqued; surface/UI pass pending. (Home's surface pass is in code but Frederik's UI critique is still pending → UI 🟠.)
- **Built, Wire 🟠 → 🟢 gated on Frederik's critique:** Chapters (P-10, list+map finder), News (P-18), Chapter page (P-11), Roze-hesje page (P-09), start-een-groep (P-23), the whole About section (P-14–P-17, P-19, P-20), Getting Started (P-12), Steun (P-04), Find a bike (P-22, UI still 🔴).
- **Back:**
  - 🟢 **live & verified:** **Chapters** (finder over real `postal_codes`, 27 pins) · **Admin/Filament** (role scoping — `LocalGroupScope`, `FilamentAdminTest`) · **Login (P-07)** — role-based auth + redirects + dev login, `UserRoleTest`/`FilamentAdminTest` green (new 2026-06-15).
  - 🟠 **in progress / faux:** Events (email opt-in placeholder) · Event detail · News · Partners (static, `D-11`) · Chapter page (P-11) · Roze-hesje page (P-09 — foto-galerij/WhatsApp/change-feed/draft-state/materials faux, await [#37](https://github.com/ndeblauw/kidicalmass/issues/37); roles + "Nieuw" marker real) · start-een-groep (P-23).
  - ⚪ **links out / static:** Steun · Help out · Getting Started · Find a bike · About leaves (Hub, Mission — live PAT-4 stats deferred — Vision, Organisation, Press).
  - ❓ **shape open:** Contact · Legal · My activities.
- **OPEN concern `D-10` (cross-cutting):** page metadata / SEO / social share previews never addressed — the public `<head>` is a stub (bare titles, hardcoded EN description, no Open Graph / Twitter Card / canonical / `hreflang`). Affects every row; needs a head-metadata partial + title pattern + per-page descriptions in voice + an OG-image-per-page-type plan. Do not call the site launch-ready until resolved. See [`01-concerns.md` § D-10](../01-concerns.md).
- **OPEN concern `D-11`:** Partners (P-20) + Press (P-19) have no real bound data — the `partners` table holds 15 seeded records (`d9343c4`) but no cleared logos / category field / table-binding; there is no Press model. Both shipped honestly static. Launch-visible site-wide: the slim `partner-strip` renders only the hardcoded Brussel Mobiliteit logo. See [`01-concerns.md` § D-11](../01-concerns.md).
- **Routed but not built:** Contact + Legal views are stubs (Wire 🔴). Legal folded — `/cookies` 301s to `/privacy`.
- **Global shell (not a P-row):** footer + slim partner strip NL-localised; the fat-footer mirrors the IA (Ontdek · Over ons · persistent **Steun Kidical Mass** CTA · utilities bottom bar); `♥ Steun ons` header CTA (login → footer-only; mobile pinned). Roze `{gemeente}` nav button for logged-in members. Social: IG `kidicalmass.belgium`, FB `Kidicalmass.brussels`.
- **Proposed build order** (from migration): Events → Chapters → Help out → Getting Started → About → Home. Validate with Nico ([25-content-migration.md](../25-content-migration.md)).
