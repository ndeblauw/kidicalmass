# Skeleton — page registry & build pipeline

Every page/route as one row, with its **honest pipeline status**. This table is the single source of truth; the read-only **`/build`** dashboard (non-prod, unlinked) parses it live. Update procedure + honesty gate live in [`CLAUDE.md`](../../../../CLAUDE.md) → "Updating the build pipeline" (or run `/pipeline`).

**Phases:** `UX` briefing · `Conf` content-confidence (1–5) · `Wire` wireframe (content + hierarchy, no style) · `Assets` media in · `UI` visual style · `Back` backend/CMS wired & verified · `OK` client sign-off.
**Status:** 🔴 niet begonnen · 🟠 bezig · 🟢 goed · ⚪ n.v.t. · ❓ te beslissen. `OK` is binary (🔴/🟢).

## Roll-up

- **Pages:** 22 rows (`P-01`–`P-22`). **UX:** 17 🟢 + 1 🟠 (My activities) + 4 🔴 (stubs: Contact, Legal, Login, Back-office). **Avg content-confidence ≈ 2.3 / 5** — client material still pending across most pages.
- **Wire/UI 🟢 (Frederik-approved):** **Help out** — the first page fully through the design pass (ride/show-kit re-skin + real volunteer photography + Frederik's own critique). Only `OK` (client sign-off) remains.
- **Built + rebranded (Wire/UI 🟠):** Home, Events, Event detail, Chapters, Chapter page, News — the six model-backed views. **Wire 🟢 is gated on Frederik's critique** — these six still await theirs (Help out is the first page through it).
- **Surface pass done (Wire 🟠, UI 🟠):** **Getting Started** — built on the ride/show kit (`.activity-hero*` / `.activity-promises*`, full-bleed colour bands, white tilted cards, red Flux-icon chips); and **Steun Kidical Mass** (P-04, built 2026-06-03 — blue hero, funds cards with red chips, ask card + light-blue free-reassurance, yellow movement-scale band; render-verified, no screenshot). Wire/UI 🟢 still gated on Frederik's critique.
- **Built at wireframe fidelity (Wire 🟠, UI 🔴):** Find a bike (the no-bike resource offshoot) — NL structural view, content verified. Surface/UI pass still pending.
- **Back:** 🟠 (in progress, unverified) on the six model-backed pages + Login (Fortify) + Partners; ❓ where need/shape is open (Contact, Legal, My activities, Back-office, Mission); ⚪ on the static About leaves + Getting Started + Find a bike + Help out (now static — its routed form lives on the chapter page) + **Steun Kidical Mass** (links out to Growfunding).
- **Routed but not built:** the static About leaves, Contact, Legal views are routed (`routes/web.php`, `{locale}` prefix) but the Blade views are still stubs — rows stay Wire 🔴. (Getting Started + Steun Kidical Mass are now built.) Legal is now **one page** — `/cookies` 301s to `/privacy` (folded 2026-06-02).
- **Cross-cutting — OPEN concern (`D-10`, flagged 2026-06-03):** **page metadata / SEO / social share previews have never been addressed.** The public `<head>` ([`layouts/site.blade.php`](../../../../resources/views/layouts/site.blade.php)) is a stub — titles are bare/unsuffixed (Help-out is just "Meehelpen"), the meta description is hardcoded English site-wide, and there are **no Open Graph / Twitter Card / canonical / `hreflang` tags**. Shared links render with no preview. Affects **every row**; not a per-P gap. Needs a head-metadata partial (build) + a title pattern, per-page descriptions in voice, and an OG-image-per-page-type plan (design). See [`01-concerns.md` § D-10](../01-concerns.md). Do not call the site launch-ready until resolved.
- **Global shell (not a P-row):** the public **footer + partner strip** are NL-localised via `lang/nl/footer.php` + `lang/nl/partners.php`. **Partner strip reworked 2026-06-03:** the full-bleed "Partners & sponsors" band (logos + acquisition + "Ook ondersteund door" + illustration) was reduced to a **slim recognition strip** ([PAT-5](../40-patterns.md)) — "Mede mogelijk gemaakt door" + muted logos + one link → `/about/partners`; acquisition + supporters list + categories moved to **P-20**. Brief: [`partners.md`](partners.md). The **fat-footer menu mirrors the IA** — *Ontdek* (main nav), *Over ons* (About sub-nav), persistent **Steun Kidical Mass** CTA → `/steun-ons`, and a utilities bottom bar (Contact · Privacy & cookies · Inloggen). Social = Instagram + Facebook (IG `kidicalmass.belgium`, FB `Kidicalmass.brussels`). **Support rework built 2026-06-03:** the header carries a **`♥ Steun ons`** accent CTA (replaces login → login is footer-only; mobile = pinned first in the hamburger menu); "steun" replaces "lid" sitewide (`lang/nl/support.php`); reusable `<x-support-callout>` on Home + event-detail. See P-04 + [`10-scope.md` § Support](../10-scope.md).
- **Proposed build order** (from migration): Events → Chapters → Help out → Getting Started → About → Home. Validate with Nico ([25-content-migration.md](../25-content-migration.md)).
